¿Cómo se conserva el avance?

Las actividades completadas, respuestas y calificaciones se guardan automáticamente en el almacenamiento local de este navegador. No se sincronizan entre dispositivos, no son un registro oficial institucional y pueden desaparecer si se eliminan los datos del navegador.

Dentro de la clase podrás exportar un respaldo JSON y volver a importarlo después. La entrega al docente debe hacerse mediante el sistema institucional o el medio que este indique.
