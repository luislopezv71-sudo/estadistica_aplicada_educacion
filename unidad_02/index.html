1. Teoría ampliada: describir no es explicar

Distribuciones y frecuencias

Una distribución revela cuántas observaciones tienen cada valor o pertenecen a una categoría. La frecuencia absoluta es el conteo; la relativa es el conteo dividido entre el total válido; la acumulada suma frecuencias de categorías ordenadas o intervalos.

La frecuencia acumulada tiene sentido para una variable ordenada, pero no para modalidades educativas nominales como presencial y virtual. Los datos faltantes deben reportarse por separado.

Gráficas adecuadas

Para categorías nominales, utilice gráficas de barras. Para variables cuantitativas, histograma y diagrama de caja. Evite interpretar la forma de una distribución solamente con una gráfica de sectores o usar un histograma para categorías.

Tendencia central

Media: x̄ = Σxᵢ/n; usa todos los valores y es sensible a extremos. Mediana: dato central de los valores ordenados, o promedio de los dos centrales si n es par. Moda: valor más frecuente; puede haber varias modas o ninguna moda única. Su pertinencia depende de la variable y la pregunta.

Posición y dispersión

Rango: máximo menos mínimo. Cuartiles: separan aproximadamente en cuatro partes la distribución ordenada; pueden cambiar con el algoritmo adoptado. RIC: Q3 − Q1. Varianza muestral: s² = Σ(xᵢ−x̄)²/(n−1). Desviación estándar muestral: s = √s². La varianza queda en unidades cuadradas; la desviación estándar conserva las unidades del indicador.

Valores atípicos: un criterio exploratorio usa límites Q1 − 1.5×RIC y Q3 + 1.5×RIC; no son una orden automática para eliminar registros. Un valor extremo debe investigarse antes de decidir su tratamiento.

Interpretación educativa rigurosa

La media por sí sola puede ocultar desigualdades. Compare mediana, dispersión, extremos y distribución. Distinga desempeño individual de desempeño del grupo; además, recuerde que calificaciones de instrumentos distintos no siempre son comparables.

Las comparaciones descriptivas de grupos ficticios no prueban superioridad causal de una modalidad ni pueden generalizarse a estudiantes reales.

2. Ejemplos resueltos paso a paso

Ejemplo A: dos grupos con media idéntica

Grupo A: 8, 8, 8, 8, 8. Grupo B: 5, 6, 8, 10, 11 (escala ilustrativa de puntos, no calificaciones limitadas a 10).

  1. Sumar A = 40 y B = 40.
  2. Dividir entre cinco: ambas medias son 8.
  3. Ordenar valores: la mediana de ambos grupos es 8.
  4. Rango A = 8−8 = 0; rango B = 11−5 = 6.
  5. Varianza muestral A = 0. Para B: desviaciones −3, −2, 0, 2, 3; cuadrados 9+4+0+4+9=26; varianza muestral =26/4=6.5; desviación estándar ≈ 2.55.
Interpretación: promedios y medianas idénticos no implican desempeño homogéneo. El grupo B muestra mayor variabilidad y requiere analizar apoyos diferenciados.

Ejemplo B: promedio sensible a un valor extremo

Horas de estudio: 2, 3, 3, 4, 18.

  1. Media = (2+3+3+4+18)/5 = 6 horas.
  2. Mediana = tercer dato ordenado = 3 horas.
  3. La observación 18 eleva la media. Antes de excluirla, verificar si es plausible y fue registrada correctamente.
En un reporte pedagógico conviene mostrar ambas medidas y explicar la asimetría, no elegir la que parezca más favorable.

Parte B: jamovi (8 minutos)

  1. Abra el CSV y configure Modalidad como nominal y Calificacion_final como continua.
  2. Vaya a Análisis → Exploración → Descriptivos. Solicite media, mediana, desviación estándar, mínimo, máximo, cuartiles, histograma y diagrama de caja.
  3. Utilice Split by / Dividir por con Modalidad para comparar descripciones.
