## Subir a tu repositorio existente

1. **No borres el repositorio ni reemplacen las carpetas `unidad_01`, `unidad_02` o `assets`.**
2. Copia el contenido completo de este ZIP a la raíz del repositorio `estadistica_aplicada_educacion`, permitiendo reemplazar únicamente `index.html` y `recursos.json`.
3. Verifica que exista `unidad_03/index.html`, `unidad_03/clase.js`, `materiales/Clase03_muestreo_sintetico.csv`.
4. Confirma los cambios mediante GitHub Desktop o una confirmación en GitHub, o usa `git add index.html recursos.json unidad_03 materiales/Clase03_muestreo_sintetico.csv; git commit -m "Clase 03: probabilidad y muestreo"; git push`.
